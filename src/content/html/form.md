## フォーム全体の基本原則（formタグ）

フォーム要素を配置する際は、データの送信先（アクション）と送信方法（メソッド）を明確にし、適切な属性を持った `<form>` タグで全体を囲んでください。

### どういうときに使うか（選定基準）
* お問い合わせ、会員登録、ログイン、検索窓など、**「ユーザーが入力した情報をサーバーに送信する」** エリアには、必ず `<form>` タグが必要です。
* `<form>` タグがないと、ブラウザの「Enterキーを押して送信する」といった標準機能や、パスワード管理ツールの自動入力（オートフィル）が正常に動作しなくなります。

### 運用ルール
* **action属性とmethod属性の明記：**
  データの送信先（`action`）と、通信方法（`method`）を必ず記述します。一般的な入力フォームではデータを安全に送るために `method="post"` を使用し、サイト内検索などの場合は `method="get"` を使用します。

```html
<form action="/contact/confirm/" method="post">
</form>
```

## ラベルの紐付け（labelタグ）

入力項目（`<input>` や `<textarea>` など）には、それが何を入力する場所なのかを示すタイトル（ラベル）を必ず `<label>` タグを用いてプログラム的に紐付けてください。

### どういうときに使うか（選定基準）
「お名前」「メールアドレス」といったテキストだけでなく、チェックボックスやラジオボタンなど、すべての入力要素に対して必ずペアで適用します。

### 運用ルール
明示的な紐付け：
`<label>` タグの for 属性の値と、入力要素の id 属性の値を完全に一致させて紐付けます。

クリック領域の拡大（UX向上）：
正しく紐付けを行うことで、テキスト部分（例：「利用規約に同意する」という文字）をクリックした際にも、隣の小さなチェックボックスにチェックが入るようになります。

```html
<form action="/contact/confirm/" method="post">
  <div class="form-group">
    <label for="user-email">メールアドレス</label>
    <input type="email" id="user-email" name="email">
  </div>

  <div class="form-checkbox">
    <input type="checkbox" id="agree-terms" name="agreement" value="yes">
    <label for="agree-terms">利用規約に同意します</label>
  </div>
</form>
```

### 入力項目のマークアップ（input / textarea / select）

入力させたいデータの種類（テキスト、数値、選択肢など）に応じて、最も適切なHTML5の要素や `type` 属性を選択してください。

### どういうときに使うか（選定基準）
- `<input type="text">`: 通常の1行テキスト（住所、会社名など）。
- `<input type="email">` / `<input type="tel">`: メールアドレスや電話番号。これらを指定することで、スマートフォンで入力する際、最初から「英数字キーボード」や「テンキー（数字）画面」が自動で立ち上がり、ユーザーの入力ストレスが激減します。
- `<textarea>`: お問い合わせ内容や備考欄など、複数行の長文を入力させる場合。
- `<select>`: 都道府県の選択など、あらかじめ決まった多くの選択肢から1つを選ばせる場合。

### 運用ルール
name属性の必須化：
すべての入力要素には、プログラムがデータを識別するための name 属性を必ず記述 してください。name 属性がない項目は、送信ボタンを押してもサーバーにデータが届きません。

required属性の活用：
必須入力の項目には required 属性を記述し、ブラウザ側での標準バリデーション（未入力時のアラート）を有効にします。

## プレースホルダーの扱い（placeholder属性）

入力欄の中に薄いグレーの文字で、入力例などを表示させる `placeholder` 属性は、あくまで「補助的なヒント」として正しく運用してください。

### 運用ルール
- ラベル代わりの使用は禁止：
デザインをスッキリさせたいからといって、<label> タグを隠して `placeholder="メールアドレスを入力"` のようにラベルの代わりに使うことは完全に禁止とします。
- 入力開始時に消えるリスクの考慮：
プレースホルダーは、ユーザーが1文字でも文字を入力すると画面から消えてしまいます。そのため、入力中に「ここは何の項目だったっけ？」とユーザーが迷子になる原因になります。

## 送信ボタンの注意点

- フォームの最後に配置する「送信する」「確認画面へ」といったボタンは、必ず適切な要素と属性で記述してください。
button要素（type="submit"）を使用する：
フォームを送信するボタンには、必ず `<button type="submit">` を使用してください。
- aタグによる送信JavaScriptの禁止：
「インライン要素の使い分け（a と button）」に準拠し、`<a href="#" onclick="...">` を使ってJavaScriptでフォームを送信させる古い実装はバグやセキュリティ、アクセシビリティの観点から禁止します。

```html
<div class="form-actions">
  <button type="submit" class="c-button-primary">確認画面へ進む</button>
</div>
```
